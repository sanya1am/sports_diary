Дневник качка.

Приложение будет предназначено для ведения персонального дневника тренировок в зале.
Пользователь сможет составлять свои тренировочные программы, указывать веса, количество подходов, повторений и отслеживать прогресс. К тому же, пользователь сможет вводить и отслеживать изменения в своем теле, будь это вес или обхват мышц.
